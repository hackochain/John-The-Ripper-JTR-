Password Hash Analysis and Recovery Using John the Ripper and Johnny

### 1. Objective
To analyse password hashes from three files and perform password recovery using John the Ripper (JTR) and its graphical interface, Johnny.

### 2. Tools Used
- Kali Linux
- John the Ripper (JTR)
- Johnny
- Wordlist (`password.lst`)

### 3. Work Performed
1. Verified the installation of John the Ripper in Kali Linux.
2. Created separate text files to store individual password hashes.
3. Identified the hash format as PDF.
4. Used John the Ripper to analyse the hashes through terminal commands.
5. Applied wordlist-based dictionary attacks using `password.lst`.
6. Used Johnny to perform password auditing through a graphical interface.
7. Successfully recovered the passwords for all three files.

### 4. Outcome
Successfully analysed three PDF password hashes and recovered their corresponding passwords using John the Ripper and Johnny.

### 5. Learning Outcome
Gained practical knowledge of password hashing, hash identification, dictionary attacks, wordlist usage, Linux commands, and password-auditing tools.

### 6. Conclusion
The task provided practical exposure to password security assessment using command-line and graphical tools. It improved my understanding of password auditing techniques and the importance of secure password practices.
